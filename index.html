Desayunos Sorpresa

Plan Pro
Preguntas frecuentes

¿Tienes dudas?

Aquí respondemos las más comunes.

¿Cuánto tiempo tarda la entrega?

Entre 5 y 10 días hábiles, dependiendo del plan. El tiempo empieza a contar cuando recibimos toda la información (logo, textos e imágenes).

¿El hosting y dominio están incluidos?

El precio del plan es solo por el diseño. El hosting + dominio (1 año) tiene un costo adicional de $150.000 COP, y nos encargamos de toda la configuración.

¿Puedo modificar la web yo mismo después?

La web es estática, así que las modificaciones las hacemos nosotros. Ofrecemos planes de mantenimiento desde $30.000/mes, o cambios puntuales desde $8.000.

¿Incluye carrito de compras real?

El Plan Premium incluye un carrito "Direct-to-WhatsApp": los productos se añaden al carrito y al final se genera un mensaje ordenado con el pedido completo para enviarlo por WhatsApp. No incluye pasarela de pago (cotización aparte).

¿Puedo cambiar de plan después?

¡Claro! Puedes empezar con el Esencial y luego subir a Pro o Premium pagando la diferencia. También puedes agregar funcionalidades puntuales como servicio adicional.

¿Qué pasa si quiero un cambio después de entregado?

Los cambios simples (texto, imagen, color) tienen un costo desde $8.000. También ofrecemos planes de mantenimiento mensual desde $30.000 con 2 cambios incluidos.

¿Cómo se realiza el pago?

Anticipo del 50% para empezar, 50% contra entrega. Aceptamos Nequi, Daviplata, transferencia bancaria y PayPal.

¿Trabajan con negocios de toda Colombia?

Sí. Trabajamos 100% remoto con negocios de todo el país. La comunicación es por WhatsApp, correo y videollamadas.

¿Listo para empezar?
